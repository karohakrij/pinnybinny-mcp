# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Contact us privately at: **security@pinnybinny.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond within 72 hours and coordinate disclosure with you.

## Scope

This repository contains schemas, examples, and documentation for the PinnyBinny MCP server.  
The MCP server itself runs at `https://b.pinnybinny.com/api/mcp/v1`.

Security issues in the live server (authentication bypass, data leakage, rate limit bypass) are in scope.

## Out of scope

- Issues requiring physical access
- Social engineering
- Denial of service against the MCP endpoint
